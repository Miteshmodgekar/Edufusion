02 / 09
THE PROBLEM
What was broken in the department?
📊
Manual attendance
Faculty calculated attendance by hand from registers. Errors were common, defaulters were identified too late.
📝
Unstructured leaves
Leave requests were informal, approvals untracked, and attendance adjustments done inconsistently.
⚠️
Late risk detection
At-risk students were identified only at exam time — too late for meaningful intervention.
💼
Disconnected placement
No unified view of student placement readiness, skills, certifications, or internship history.
🔔
No alert system
Students had no proactive notifications about attendance shortfall, risk levels, or placement updates.
📱
No mobile access
All processes required desktop access. No mobile-friendly or offline-capable interface existed.

06 / 09
MACHINE LEARNING
Prediction + Risk classification
PASS/FAIL PREDICTION — LOGISTIC REGRESSION
Features: [attendance %, internal marks, external marks]

PASS if:
 · attendance ≥ 75%
 · internal ≥ 20 / 50
 · external ≥ 35 / 100
 · total ≥ 50 / 150

Output: PASS / FAIL + confidence %
WHAT-IF SIMULATOR FORMULA
Projected % = ((A + X) / (T + X)) × 100

Classes needed:
X = ⌈(85T − 100A) / (100 − 85)⌉
RISK CLASSIFICATION — RULE-BASED
ConditionScore
Attendance < 75%+3
Attendance 75–85%+2
Internal < 15/50+3
Internal 15–25/50+2
Project < 30%+2
Project 30–60%+1
HIGH — score ≥ 5 → immediate intervention
MEDIUM — score 2–4 → monitor + counselling
LOW — score 0–1 → performing well
